## 0. 로직 — 지금 계산기가 어떻게 동작하는가

두 도구 모두 **목표 비중(%)을 금액으로 바꾼 뒤, 가격으로 나눠 정수 주수를 구하고, 남는 돈은 현금**으로 둡니다.  
차이는 **총 금액의 정의**와 **이미 갖고 있는 주식의 유무**입니다.

### 0.1 공통 규칙

| 단계 | 내용 |
|------|------|
| ① 총 금액 | 도구마다 정의가 다름 (아래) |
| ② 할당 금액 | `총 금액 × (종목 비중 ÷ 100)` |
| ③ 목표 수량 | `floor(할당 금액 ÷ 주당 가격)` — **정수만** |
| ④ 현금 | `총 금액 − 주식에 쓴 금액` (비중 미입력 분 + 내림 잔액) |
| 비중 합 &gt; 100% | 계산 불가 (입력 수정) |
| 비중 합 &lt; 100% | 나머지 %는 **의도적 현금** |
| 세금·수수료 | **미포함** (참고용 계산) |

### 0.2 단순 매수 리밸런싱 계산 (`calculateRebalancing`)

**전제:** 아직 보유 종목이 없거나, “이번에 쓸 매수 예산만” 나눌 때.

```
총 금액 = 사용자가 입력한 「총 매수 금액」

종목 A 할당 = 총 금액 × A비중%
종목 A 매수 수량 = floor(A 할당 ÷ A 가격)
…
현금 = 총 금액 − Σ(매수 수량 × 가격)
```

- **매도 없음.** 결과표는 매수 수량·금액·비중·현금.
- 예: 100만 원, A 50%·B 40% → A·B에 각각 할당 후 내림, 미입력 10% + 잔액은 현금.

### 0.3 포트폴리오 기반 리밸런싱 계산 (`calculateTargetRebalance`)

**전제:** 이미 가진 종목이 있고, 목표 비중에 맞추려고 **추가 매수(필요 시 매도)** 할 때.

```
총 금액 = (현재가로 평가한 기존 보유액) + (추가 매수 금액)

※ 같은 이름 신규 행에 다른 가격이 있으면, 기존 보유분도 그 가격으로 재평가

종목별 목표 수량 = floor(총 금액 × 비중% ÷ 가격)

보유 수량 &gt; 목표 → 매도
보유 수량 = 목표 → 홀딩
보유 수량 &lt; 목표 → 매수

현금 = 총 금액 − 최종 주식 평가액
```

- 결과: **매수 탭 / 매도 탭**, 최종 보유 내역, 현금 행.
- 포트폴리오 저장·불러오기는 **브라우저 로컬** (계산 로직과 별개 UI).

### 0.4 한눈에 비교

| | 단순 매수 | 포트폴리오 기반 |
|--|----------|----------------|
| 총 금액 | 매수 예산만 | 보유 평가 + 추가 매수 |
| 입력 | 금액, 종목명·가격·비중 | 보유(이름·가격·수량) + 추가금액 + 목표비중 |
| 매도 | 없음 | 있음 (목표보다 많이 가진 종목) |
| 쓰임 | 신규 납입·첫 배분 | 기존 포트폴리오 재조정 |

### 1.1 배치

```
[사용 방법]  h3
[① 아이콘] [② 아이콘] [③ 아이콘]     ← 기존 3스텝 (모드별 문구)

              [ 자세히 ▾ ]             ← 신규: 텍스트/고스트 버튼, 스텝 아래 중앙 또는 우측

┌─ 아코디언 패널 (열렸을 때만) ─────────────────┐
│  제목: {현재 모드} 사용 방법                   │
│  …섹션 본문…                                  │
└──────────────────────────────────────────────┘
```

- **닫힘 기본.** 「자세히」 토글. 열린 상태 아이콘 `▴` / 닫힘 `▾`.
- **모드 카드 전환 시** 아코디언은 **유지해도 되고 닫아도 됨** → 권장: **열린 채면 본문만 교체** (다시 펼칠 필요 없음).
- 모바일: 패널 전체 폭, 제목·본문 세로 스택.
- SEO: 답변과 같이 **펼침 여부와 무관하게 DOM에 두 모드 본문을 모두 넣지 말고**, 현재 모드 본문만 렌더해도 됨. (검색용 장문은 FAQ·가이드 담당. 여기는 UX 도움말.)  
  원하면 `details`로 두 모드 각각 넣어 크롤러에 노출 가능 → **P1은 현재 모드만**, SEO 장문은 기존 FAQ 유지.

### 1.2 카피 톤

- 짧은 문장, 투자 자문 아닌 **조작·해석 안내**.
- 숫자 예시는 **한 세트만** (과한 표 금지).
- 면책 한 줄: “실제 주문·세금·수수료는 반영되지 않습니다.”

## 3. 단순 매수 리밸런싱 — 자세히 본문 기획

### 3.1 한 줄 설명
이번에 쓸 **매수 금액**을 목표 비중대로 나눠, 종목별 **정수 매수 수량**과 **남는 현금**을 보여 줍니다. 기존 보유·매도는 다루지 않습니다.

### 3.2 입력 항목별 설명

| 입력 | 설명 포인트 |
|------|-------------|
| 통화 | 표시 단위만 바뀜. 계산 식은 동일. 언어를 바꾸면 기본 통화가 따라감(통화만 바꿔도 언어는 안 바뀜). |
| 총 매수 금액 | “이번에 주식 사는 데 쓸 전체 예산”. 이 값이 곧 총 금액. |
| 종목명 | 구분용 이름. 결과는 이 이름 기준으로 표시. |
| 주당 가격 | 할당 금액을 나눌 단가. 실제 호가와 다를 수 있음 → 참고용. |
| 비중 (%) | 총 매수 금액 중 이 종목에 쓸 비율. 합이 100% 미만이면 나머지는 현금. |
| 종목 추가 | 행을 늘려 여러 종목에 배분. |

### 3.3 결과 해석

| 결과 | 읽는 법 |
|------|---------|
| 목표 매수 금액 | 총액 × 비중 (이상적인 금액) |
| 매수 수량 | 그 금액을 가격으로 나눈 **내림** 주수 |
| 실제 매수 금액 | 수량 × 가격 |
| 실제 비중 | 총 매수 금액 대비 실제 매수 금액 비율 |
| 현금 | 예산 중 주식에 안 쓴 금액 (미입력 비중 + 내림 잔액) |

**숫자 예시 (본문에 짧게):**  
총 매수 100만 원 · A 50% · 주가 3만 원 → 할당 50만 · floor(50만/3만)=16주 · 실제 48만 · 나머지·미할당은 현금.

### 3.4 이런 상황에서 유용합니다

- 매달/분기 **신규 납입금만** ETF·주식에 비중대로 나눠 사고 싶을 때  
- 계좌에 아직 해당 종목이 없고 **첫 매수 계획**만 필요할 때  
- 매도 없이 **매수 수량만** 빠르게 보고 싶을 때  

### 3.5 주의할 점

- 보유 중 포트폴리오를 목표 비중에 **다시 맞추려면** → 포트폴리오 기반 도구 사용.  
- 결과는 주문 실행이 아님. 호가·수수료·세금 확인 후 거래.

## 4. 포트폴리오 기반 리밸런싱 — 자세히 본문 기획

### 4.1 한 줄 설명
**지금 가진 종목**과 **추가할 돈**을 합친 총액에 목표 비중을 적용해, 종목별 **매수·매도 수량**과 **최종 보유·현금**을 보여 줍니다.

### 4.2 입력 항목별 설명

**A. 기존 포트폴리오**

| 입력 | 설명 포인트 |
|------|-------------|
| 종목명 / 주당 가격 / 보유 수량 | 현재 포지션. 평가액 = 가격 × 수량. |
| 저장·불러오기 | 같은 브라우저에 이름 붙여 보관. 서버 전송 없음. |

**B. 추가 매수**

| 입력 | 설명 포인트 |
|------|-------------|
| 추가 매수 금액 | 이번에 새로 넣는 현금. 총 금액 = 보유 평가 + 이 금액. |
| 총 평가 금액 (안내 문구) | 계산에 쓰이는 합계. 신규 행 가격이 다르면 보유분이 재평가될 수 있음. |
| 포트폴리오 행 (*포트폴리오) | 보유 종목이 목록에 미러링. 목표 비중·가격 수정 가능. |
| 수동 추가 행 | 신규 매수 종목 또는 동명으로 **다른 가격** 입력(가격 불일치 안내). |
| 비중 (%) | **최종 포트폴리오(총 금액 기준)** 목표 비중. 동명 수동 행이 있으면 비중은 그쪽. |

### 4.3 결과 해석

| 결과 | 읽는 법 |
|------|---------|
| 기존 평가 / 추가 매수 / 총 운용 금액 | 총 금액 구성 |
| 매수 금액·매도 금액 | 실제 제안된 매매 규모 |
| 매수 탭 / 매도 탭 | 종목별 수량·거래 금액 |
| 최종 보유 내역 | 리밸런싱 후 수량·평가·비중 (+ 현금 행) |
| 잔여 현금 | 총 금액 − 최종 주식 평가 |

**해석 팁:**  
“가장 많이 오른 종목을 팔라”고 나와도, 목표가 넘어서이지 **종목 추천이 아님**.

### 4.4 이런 상황에서 유용합니다

- 이미 VOO·QQQ·개별주 등을 갖고 있고 **목표 비중이 어긋났을 때**  
- **추가 적립**과 함께 비중을 맞추고 싶을 때  
- 매수만으로 안 되고 **일부 매도가 필요한지** 보고 싶을 때  

### 4.5 주의할 점

- 동명·다른 가격이면 보유 평가가 신규 가격 기준으로 바뀌어 총액이 달라질 수 있음 (안내 문구 확인).  
- 세금·수수료·호가 미반영. 매도 전 과세 여부 별도 확인.
